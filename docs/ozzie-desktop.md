# Ozzie desktop integration

The personal Ozzie wrapper and Agents-panel customization are in `contrib/ozzie-desktop`. See its README for build, local installation, configuration, and verification. This is an optional user customization; it changes no packaged default, global agent order, authentication data, or system service.

The Agents clone presents Ozzie with the user's existing TuxTerm animation between Codex and Muse. Animation stops when the drawer is closed or shell animations are disabled. The app presents Ozzie and Plugins controls and a top-right Close button.

The Dot URL lives in user configuration rather than source. Browser profiles and credentials are excluded. User settings are backed up separately in the private `veltri-23/omarchy-setup` repository.
